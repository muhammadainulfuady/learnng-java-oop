###Ada dua aturan emas yang harus lu ingat:

1. Upcasting (Anak ke Bapak): Dilakukan secara otomatis karena Java tahu kalau setiap Spiderman sudah pasti seorang Hero.

2. Downcasting (Bapak ke Anak): Harus dilakukan secara manual dan hati-hati (pakai instanceof) karena belum tentu setiap Hero itu adalah Spiderman.
